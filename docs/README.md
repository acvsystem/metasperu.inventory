# Documentacion del sistema de inventario

Esta carpeta contiene la documentacion funcional y operativa del proyecto de inventario METAS PERU.

## Documentos

- [Manual de usuario](./MANUAL_USUARIO.md): guia para administradores, auditores y usuarios Pocket.
- [Diagramas de uso](./DIAGRAMAS.md): flujos principales del sistema usando Mermaid.
- [Guia tecnica y operativa](./GUIA_TECNICA_OPERACION.md): arquitectura, despliegue, operacion, soporte y controles recomendados.

## Alcance

La documentacion cubre:

- Gestion de sesiones de inventario.
- Uso de Pocket en modo online y manual.
- Sincronizacion y control de pendientes.
- Dashboard de monitoreo.
- Cruce de inventario.
- Productos sin exhibir.
- Exportacion de reportes.
- Configuracion de zonas y subzonas.
- Chat de notificaciones por socket.
- Recomendaciones tecnicas para desarrollo y soporte.

## Recomendacion

Actualizar estos documentos cada vez que se agregue un modulo, se cambie un flujo operativo o se modifique el formato de reportes.
